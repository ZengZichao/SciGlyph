# Five visual series

The library is organized into five visual series (the `series` field; filterable in manifests and the gallery):

| series | Description | Positioning |
|---|---|---|
| `classic` | Classic scientific illustration | Clean line work with flat low-saturation fills, for textbooks and review figures. |
| `atlas` | Microbe atlas | Atlas-level detail: leader-line labels, scale bars, color-blind-safe semantic colors. |
| `icon24` | 24×24 line icons | Uniform grid and stroke, ideal for UI and small in-figure use. |
| `primitives` | General scientific primitives | Cross-discipline building blocks: arrows, chart skeletons, circuit and flow symbols. |
| `labflow` | Lab workflow & equipment | Equipment block diagrams, workflow nodes and safety signage with readable flow direction. |

Three formats (the `format` field):

| format | Meaning |
|---|---|
| `illustration` | Illustration |
| `diagram` | Diagram / chart |
| `icon` | Icon (currentColor, re-tintable) |
